RenoCare แบบ Docker บนแฟลชไดร์ฟ
================================

เครื่องที่จะเปิดต้องมี
  - Windows 10/11 + Docker Desktop (เปิดไว้จนขึ้น Engine running)
  - ครั้งแรกในเครื่องนั้นต้องต่ออินเทอร์เน็ต (Docker โหลด image mysql / node และติดตั้ง package)
    ครั้งต่อไปไม่ต้องต่อเน็ต

วิธีใช้
  1. ดับเบิลคลิก START-RenoCare.bat
     - สร้าง container ทั้งระบบ แล้วนำข้อมูลจากแฟลชไดร์ฟ (data\) เข้า Docker
     - เบราว์เซอร์เปิด http://localhost:3090 ให้เอง
  2. ใช้งานตามปกติ
  3. ใช้เสร็จ ดับเบิลคลิก STOP-RenoCare.bat
     - บันทึกข้อมูลจาก Docker กลับลงแฟลชไดร์ฟ แล้วปิด container
     - ** ต้องทำก่อนถอดแฟลชไดร์ฟ ไม่อย่างนั้นสิ่งที่บันทึกในเครื่องนี้จะไม่ติดไปกับแฟลชไดร์ฟ **
  - SAVE-data.bat  บันทึกลงแฟลชไดร์ฟระหว่างใช้งาน (ไม่ปิดระบบ)

ข้อมูลไหลยังไง
  แฟลชไดร์ฟ (data\*.sql) ──START──▶ Docker ในเครื่องนั้น ──STOP/SAVE──▶ แฟลชไดร์ฟ
  - data\STAMP.txt คือรหัสชุดข้อมูล START จะกู้ข้อมูลเข้า Docker เฉพาะเมื่อรหัสไม่ตรงกับที่อยู่ใน Docker
    (เปิดซ้ำในเครื่องเดิมโดยไม่ได้ไปแก้ที่เครื่องอื่น ข้อมูลในเครื่องจะไม่ถูกทับ)
  - ถ้าใช้หลายเครื่อง ให้ STOP ที่เครื่องเก่าก่อนไปเปิดเครื่องใหม่เสมอ
    ไม่อย่างนั้นสิ่งที่ทำในเครื่องเก่าหลัง SAVE ครั้งล่าสุดจะหาย

แยกจากชุดพัฒนา
  ชื่อ container ขึ้นต้นด้วย renocare_usb_ และใช้พอร์ต 3090 / 3316 / 8091
  เครื่องที่มีโปรเจกต์ RenoCare (พอร์ต 3000) อยู่แล้ว เปิดพร้อมกันได้ ข้อมูลไม่ทับกัน

ถ้ามีปัญหา
  - "ยังไม่ได้เปิด Docker Desktop"  เปิด Docker Desktop รอให้พร้อม แล้วลองใหม่
  - port is already allocated      มีโปรแกรมอื่นใช้พอร์ต 3090/3316/8091 อยู่ ปิดโปรแกรมนั้นก่อน
  - เปิดหน้าเว็บแล้ว login ไม่ได้     ต้องเข้าที่ http://localhost:3090 (ไม่ใช่ 127.0.0.1)
  - อยากล้างทุกอย่างในเครื่องนั้น     docker compose -p renocare_usb down -v
    (ลบเฉพาะในเครื่อง ข้อมูลในแฟลชไดร์ฟยังอยู่)
